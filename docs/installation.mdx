title: Installation
description: Install any UI Assets item into your project with the shadcn CLI.
order: 1
---

Every UI Assets item — component, hook, or block — installs with a single shadcn CLI command. There's
nothing to configure up front; the CLI resolves the item, copies its source into your project, and
adds any missing dependencies.

## Install an item

Replace `acme-ui` below with the name of the item you want (for example `copy-button`):

```sh
npx shadcn@latest add acme-ui
```

```sh
pnpm dlx shadcn@latest add acme-ui
```

```sh
yarn dlx shadcn@latest add acme-ui
```

```sh
bunx --bun shadcn@latest add acme-ui
```

## Add UI Assets as a registry (optional)

If you plan to install multiple items, add UI Assets to your project's `components.json` so you can
reference items by short name:

```json
{
  "registries": {
    "@assets": "https://ui-assets-edison.vercel.app/r/{name}.json"
  }
}
```

```sh
npx shadcn@latest add @assets/acme-ui
```

You can also install any item directly by its full registry URL without adding it to
`components.json` first:

```sh
npx shadcn@latest add https://ui-assets-edison.vercel.app/r/acme-ui.json
```
