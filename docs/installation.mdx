---

Every UI Assets item installs with a single shadcn CLI command. There's nothing to configure up
front; the CLI resolves the item, copies its source into your project, and adds any missing
dependencies.

UI Assets is organized into ten separate registries, each with its own namespace:

| Registry            | Namespace              |
| ------------------- | ---------------------- |
| Stark Components    | `@stark-components`    |
| Stark Templates     | `@stark-templates`     |
| Stark Icons         | `@stark-icons`         |
| Stark Logos         | `@stark-logos`         |
| Stark Illustrations | `@stark-illustrations` |
| Stark Fonts         | `@stark-fonts`         |
| Stark Images        | `@stark-images`        |
| Stark Videos        | `@stark-videos`        |
| Stark Backgrounds   | `@stark-backgrounds`   |
| Stark External      | `@stark-external`      |

## Add the registries to your project

Add the registries you need to your project's `components.json`:

```json
{
  "registries": {
    "@stark-components": "https://ui-assets-edison.vercel.app/r/components/{name}.json",
    "@stark-templates": "https://ui-assets-edison.vercel.app/r/templates/{name}.json",
    "@stark-icons": "https://ui-assets-edison.vercel.app/r/icons/{name}.json",
    "@stark-logos": "https://ui-assets-edison.vercel.app/r/logos/{name}.json",
    "@stark-illustrations": "https://ui-assets-edison.vercel.app/r/illustrations/{name}.json",
    "@stark-fonts": "https://ui-assets-edison.vercel.app/r/fonts/{name}.json",
    "@stark-images": "https://ui-assets-edison.vercel.app/r/images/{name}.json",
    "@stark-videos": "https://ui-assets-edison.vercel.app/r/videos/{name}.json",
    "@stark-backgrounds": "https://ui-assets-edison.vercel.app/r/backgrounds/{name}.json",
    "@stark-external": "https://ui-assets-edison.vercel.app/r/external/{name}.json"
  }
}
```

## Install an item

Replace `acme-ui` below with the name of the item you want (for example `copy-button` from
`@stark-components`):

```sh
npx shadcn@latest add @stark-components/acme-ui
```

```sh
pnpm dlx shadcn@latest add @stark-components/acme-ui
```

```sh
yarn dlx shadcn@latest add @stark-components/acme-ui
```

```sh
bunx --bun shadcn@latest add @stark-components/acme-ui
```

Swap the namespace prefix for any of the other registries above to install from them instead.

You can also install any item directly by its full registry URL without adding it to
`components.json` first:

```sh
npx shadcn@latest add https://ui-assets-edison.vercel.app/r/components/acme-ui.json
```
