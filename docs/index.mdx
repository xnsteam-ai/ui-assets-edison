UI Assets is a collection of copy-paste dev utility components, hooks, and blocks for React. Each
item is plain, readable source code — no runtime package to install, no black-box abstraction to
work around. You add exactly the code you need, and you own it from that point on.

Everything here is installable with the shadcn CLI. Pick an item from the catalog, run one install
command, and the source lands directly in your project, ready to read, customize, and extend.

## Four registries

UI Assets is organized into four separate sub-registries, each with its own namespace:

- **Stark Components** (`@stark-components`) — reusable, production-ready UI components built
  with Stark's design system for consistent web and desktop experiences.
- **Stark Icon + Logo + Illustration** (`@stark-icons`) — Stark's official icons, logos, and
  illustrations, built with a clean, minimal, bold, and consistent visual language.
- **Stark Font** (`@stark-fonts`) — Stark's fonts and typography, providing consistent font
  styles, weights, and typographic utilities.
- **Stark Images & Video** (`@stark-media`) — curated, reusable visual assets optimized for
  consistent use across modern web and desktop apps.

Browse the catalog to see what's available, or head to the installation guide to add your first
item.
