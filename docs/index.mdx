UI Assets is a collection of copy-paste dev utility components, hooks, and blocks for React. Each
item is plain, readable source code — no runtime package to install, no black-box abstraction to
work around. You add exactly the code you need, and you own it from that point on.

Everything here is installable with the shadcn CLI. Pick a component, hook, or block from the
catalog, run one install command, and the source lands directly in your project under your own
component and hook directories, ready to read, customize, and extend.

Browse the catalog to see what's available, or head to the installation guide to add your first
item.
