A self-contained SVG mark. It sizes with `className`, so it drops into an app grid, a nav, or a
favicon-scale slot without extra wrapping.

```tsx
import { StarkMarkSpark } from "@/components/ui/stark-mark-spark";

<StarkMarkSpark className="size-16" />
```
