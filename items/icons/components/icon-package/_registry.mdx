The package icon. Artwork from
[HugeIcons](https://hugeicons.com) under the MIT licence, inlined so the component installs with
**no runtime dependency**.

```tsx
import { IconPackage } from "@/components/ui/icon-package";

<IconPackage className="size-6" />
```

Need more than the curated set? `@stark-icons/hugeicons` wraps the full library of roughly 7,000
free icons.
