Real non-repeating noise from an inline `feTurbulence` filter in a data URI, so there is no raster asset and the texture scales to any size. The speckle lattice and tint wash layer over it.

```html
<div class="stark-bg-paper-grain">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-paper-grain" style="--grain-scale: 0.82; --fibre-angle: 0deg">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
