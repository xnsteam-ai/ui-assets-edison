A ruled grid built from four stacked linear gradients: minor lines on one lattice, major lines on a multiple of it. The hover wash is CSS-only — it lights the grid from the centre on hover rather than following the pointer, which would need JavaScript.

```html
<div class="stark-bg-line-grid">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-line-grid" style="--cell-width: 48px; --cell-height: 48px">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
