Each layer is a repeating tile carrying several stars at irregular positions, so the repeat period is the whole tile rather than a single star — a one-star-per-cell lattice reads as a grid no matter how it is offset. A single background-position animation moves each layer group a different distance, which is what produces the parallax.

```html
<div class="stark-bg-starfield">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-starfield" style="--star-gap: 190px; --mid-gap: 140px">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
