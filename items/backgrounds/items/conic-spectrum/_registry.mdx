A conic gradient with the origin, start angle and arc all exposed. The radial mask doubles as falloff and punches a soft hole at the origin, so the conic singularity never shows as a hard point.

```html
<div class="stark-bg-conic-spectrum">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-conic-spectrum" style="--origin-x: 50%; --origin-y: 50%">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
