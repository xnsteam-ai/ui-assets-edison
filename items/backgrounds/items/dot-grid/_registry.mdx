A dot matrix drawn from a single repeating radial gradient, masked so it dissolves into the surface
rather than stopping at a hard edge. The second `echo` layer is off by default; raising its opacity
gives the grid depth.

```html
<div class="stark-bg-dot-grid" data-preset="blueprint">
  <!-- your content -->
</div>
```

Every value is a custom property, so you can override any of them per instance without touching the
stylesheet:

```html
<div class="stark-bg-dot-grid" style="--dot-gap: 40px; --dot-color: #f472b6">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
