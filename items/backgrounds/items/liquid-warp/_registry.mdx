A shader look without WebGL. A low band count reads as poured liquid once blurred; raising it tightens toward brushed metal. The metallic conic fold on top is what separates this from a plain blurred gradient.

```html
<div class="stark-bg-liquid-warp">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-liquid-warp" style="--band-count: 5; --band-angle: 115deg">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
