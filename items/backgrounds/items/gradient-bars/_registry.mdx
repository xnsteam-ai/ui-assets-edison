The bars are one `repeating-linear-gradient` multiplied with a colour ramp, not N elements — so the bar count follows the element width with no markup. A third gradient on a period that does not divide the bar pitch varies neighbouring bars' brightness.

```html
<div class="stark-bg-gradient-bars">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-gradient-bars" style="--bar-width: 28px; --bar-gap: 12px">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
