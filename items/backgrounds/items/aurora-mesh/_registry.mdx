Four radial blooms layered and heavily blurred, drifting against each other so the wash never visibly repeats. Overlay grain hides the banding that wide flat gradients always produce.

```html
<div class="stark-bg-aurora-mesh">
  <!-- your content -->
</div>
```

Every value is a custom property, so any of them can be overridden per instance without editing the
stylesheet:

```html
<div class="stark-bg-aurora-mesh" style="--mesh-scale: 130%; --bloom-spread: 55%">…</div>
```

**Presets** set `data-preset` on the element. Choosing one in the preview changes what you see, but
the exported CSS keeps the default values in its `stark:defaults` block — add the attribute in your
own markup to use a preset.
